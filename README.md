# 🤖 AI Sentiment Detector

A simple, lightweight AI-powered sentiment analysis application built with **Python** and **Tkinter**. Analyze text and instantly discover whether its emotional tone is positive, negative, or neutral.

---

## ✨ Features

- 🧠 **Sentiment Analysis:** Analyze text using Natural Language Processing (NLP).
- 😊 **Positive Detection:** Identify positive emotions and expressions.
- 😠 **Negative Detection:** Recognize negative sentiment.
- 😐 **Neutral Detection:** Identify neutral or balanced text.
- 📊 **Sentiment Score:** Display a numerical polarity score.
- 🎨 **Modern Interface:** Clean, dark-themed graphical user interface.
- ⚡ **Lightweight:** Simple Python application with minimal dependencies.
- 🔒 **Offline Processing:** No API key or cloud service required.

## 🖥️ Preview

The application provides a simple interface where users can enter text, analyze its sentiment, and instantly view the results.

## 📦 Installation

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/AI-Sentiment-Detector.git
```

**2. Navigate to the project directory**

```bash
cd AI-Sentiment-Detector
```

**3. Install the dependency**

```bash
pip install textblob
```

**4. Run the application**

```bash
python sentiment_detector.py
```

## 🚀 How It Works

1. Enter any sentence or paragraph into the text box.
2. Click the **Analyze Sentiment** button.
3. The application processes the text using TextBlob.
4. The result is displayed with an emoji, sentiment category, and polarity score.

### Sentiment Categories

| Polarity Score | Result |
|---|---|
| Greater than 0.1 | 😊 Positive |
| Between -0.1 and 0.1 | 😐 Neutral |
| Less than -0.1 | 😠 Negative |
